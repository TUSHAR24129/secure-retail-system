# Secure Retail System

Full-stack retail web app built with Node.js, Express, and MySQL.

## Structure
- backend/ — Express API server + package.json
- database/ — MySQL schema with all ERD entities and sample data
- frontend/ — HTML pages (products, cart, orders, login)

## Setup
1. `mysql -u root -p < database/create_grocery_db.sql`
2. `cd backend && npm install && node server.js`
3. Open frontend/products.html in browser
